## Verity Desktop 0.3.0

### Any provider, for either job

- **Transcription is no longer Groq-only.** Groq Whisper, OpenAI or Gemini can
  transcribe. One Groq, OpenAI or Gemini key now runs the whole app on its own.
- **Claude and Bedrock work without a Groq key.** They can't take audio, so
  another provider transcribes and only the transcript is sent to them. The
  setup screen says which provider hears the audio.
- **Keys are kept per provider.** Switching providers no longer loses a key,
  and any answer provider pairs with any transcription provider.
- **Test makes a real request** — a one-word answer with your model, or a real
  transcription — so a retired model or a missing Bedrock model grant shows up
  on the setup screen, not mid-interview.

### Mid-sentence pauses

- A question that stops mid-sentence ("Tell me about a time when you…") is
  held for the rest of it instead of being answered by halves.
- If the interviewer is already talking again when a question is transcribed,
  Verity waits for them to finish.
- If they add to a question within 2 seconds, the answer is rewritten for the
  whole question. "Mm-hmm" and "take your time" never replace an answer.
- Questions that start with "Okay, so…", or come after a statement, are now
  recognized; "can you hear me?" is not answered.

### Faster

- New Groq default model, chosen by measurement: first word in ~140 ms vs
  ~460 ms. End to end, the first word of an answer now appears ~0.7 s after the
  interviewer stops talking (measured on the real Groq API).
- Transcription runs in parallel with answering, and connections are kept warm
  between questions.

### Fixes

- **Gemini answers work again.** The previous default, `gemini-2.0-flash`, was
  shut down by Google on 2026-06-01; saved copies of it are reset to the
  current default. Retired default models now fall through to a successor
  automatically.
- Newer OpenAI reasoning models and Gemini thinking models no longer fail on
  settings they reject.
- **Intel Macs:** the macOS download is now a universal `.dmg` (Intel and Apple
  Silicon). 0.2 shipped Apple-Silicon-only.
- A session whose audio device stream ended on its own no longer hangs.

### Installing

- **Windows:** `Verity_0.3.0_x64-setup.exe` (or the `.msi`). The installer is
  not code-signed, so SmartScreen warns — **More info → Run anyway**.
- **macOS 10.15+:** `Verity_0.3.0_universal.dmg`. It is not notarized — on
  first launch go to **System Settings → Privacy & Security → Open Anyway**.

Existing settings and keys carry over automatically.
