## Verity 0.4.1

### Scanned resumes now import

- Import a scanned PDF, a photo or a screenshot of your resume or job
  description (PNG/JPG). Verity reads the text on your computer using the
  operating system's built-in OCR (Vision on macOS, Windows OCR on Windows):
  offline, free, no key needed.
- Only the extracted text is sent to the AI, never the file.
- Extra spaces and blank lines from PDFs are stripped, so more of your
  resume fits in each prompt for the same tokens.

### Installing

Download `Verity_0.4.1_x64-setup.exe` (Windows) or
`Verity_0.4.1_universal.dmg` (macOS) below.
