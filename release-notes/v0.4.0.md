## Verity 0.4.0

### Answers that follow the conversation

- Verity now remembers the interview so far (up to 12 turns): questions it
  answered, questions the interviewer talked over, and remarks that set
  context ("We run everything on Kafka…").
- If the interviewer asks something, keeps talking, and asks more, the new
  answer covers both parts instead of losing the first.
- A 2–3 second pause to think mid-question no longer splits it in two —
  the answer is rewritten for the whole question.

### Up-to-date models

- **Gemini:** default moved to `gemini-3.6-flash` — `gemini-2.5-flash` shuts
  down on 2026-12-01. Saved copies of it are reset automatically.
- **OpenAI:** `gpt-6-luna` first — `gpt-4o-mini` shuts down on 2027-01-14.
- **Claude:** `claude-haiku-5-5`, the current Haiku, about 10× cheaper than
  Haiku 4.5.
- Groq models were checked live and are unchanged.

### New design

- Cleaner setup in three short sections, with advanced settings folded away.
- The live panel puts the answer front and centre; controls are icons and
  the history is one click away.

### Releases

- Every build of `main` now publishes its Windows and macOS installers here
  automatically.

### Installing

- **Windows:** `Verity_0.4.0_x64-setup.exe` (or the `.msi`). Not code-signed,
  so SmartScreen warns — **More info → Run anyway**.
- **macOS 10.15+ (Intel and Apple Silicon):** `Verity_0.4.0_universal.dmg`.
  Not notarized — on first launch go to **System Settings → Privacy &
  Security → Open Anyway**.

Existing settings and keys carry over.
